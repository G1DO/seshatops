## Matrix rules

- Every row begins as a reusable Planned scenario definition until an experiment
  supplies evidence.
- `Observed result` remains `Not executed` until a future experiment supplies
  evidence. M1 Issue #30 updated FC-001, FC-007, and FC-009–FC-014 only.
- `Required repetitions` for the M1 exit-gate subset is `1`. Other rows remain
  `Planned - not selected`.
- Claim IDs are stable identifiers from [EVIDENCE.md](../../EVIDENCE.md).
  Issue #30 links executed M1 rows to `CLM-003`–`CLM-006`.
- A run must complete the fields in [EXPERIMENT_REPORT.md](templates/EXPERIMENT_REPORT.md)
  and the applicable protocol; see
  [M1_EXIT_GATE_EXPERIMENT_REPORT.md](M1_EXIT_GATE_EXPERIMENT_REPORT.md).
- Failure, integrity, safety, uncertainty, and limitation artifacts must be
  retained even when the scenario does not support the intended claim.
